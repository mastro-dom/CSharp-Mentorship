## 🚀 Project overview

The **Payroll Analyzer** is a simple console application that:
- Reads a `payroll.txt` file.
- Validates each line (employee name and amount).
- Counts valid/invalid lines.
- Calculates the total payroll amount.

Example input (`payroll.txt`):
Mario Rossi;1000.50
Anna Bianchi;1200
Luigi Verdi;
;1500


Example output:

Valid lines: 2
Invalid lines: 2
Total amount: €2.200,50
